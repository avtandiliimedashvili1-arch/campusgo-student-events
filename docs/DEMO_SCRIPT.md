# CampusGo — დემოს სცენარი (დაახლოებით 2 წუთი)

1. **მთავარი გვერდი:** აჩვენე CampusGo და განმარტე, რომ ღონისძიებების მონაცემები სადემონსტრაციოა.
2. **ძიება:** აკრიფე `AI` და აჩვენე, როგორ იცვლება შედეგები.
3. **კატეგორიები:** დააჭირე „კარიერა“-ს და აჩვენე კატეგორიის ფილტრი.
4. **დეტალები:** გახსენი ღონისძიების ბარათი და აჩვენე აღწერა, დრო და ადგილი.
5. **რჩეულები:** დააჭირე გულის ღილაკს, გახსენი „რჩეულები“ და აჩვენე შენახული ღონისძიება.
6. **შენახვის შემოწმება:** განაახლე გვერდი და აჩვენე, რომ რჩეული იმავე ბრაუზერში დარჩა.
7. **შეზღუდვები:** განმარტე, რომ რეალური ღონისძიებების მონაცემები, რეგისტრაცია და მომხმარებლის ანგარიშები ამ MVP-ში არ შედის.

## მოკლე სასაუბრო ტექსტი

„CampusGo ამოწმებს იდეას, რომ სტუდენტებს შეიძლება გამოადგეთ ღონისძიებების მოსაძებნად ერთი სივრცე. ეს საჭიროება ჯერ რეალური ინტერვიუებით უნდა შემოწმდეს. MVP-ში ავირჩიე ძიება, კატეგორიის ფილტრი და რჩეულებში შენახვა, ასევე დავამატე ღონისძიების დეტალების ნახვა. პროტოტიპი მუშაობს HTML, CSS და JavaScript-ით; რჩეულები ინახება მხოლოდ ამ ბრაუზერში. შემდეგი ნაბიჯია კვლევის შედეგებით პრობლემის დაზუსტება და რამდენიმე მომხმარებელთან გამოყენებადობის ტესტირება.“
