# Prompt Engineering — CampusGo

ეს დოკუმენტი ინახავს პროექტის მთავარ პრომპტებს და იტერაციის ლოგიკას. თუ რომელიმე პრომპტი რეალურად არ გამოგიყენებია, შეცვალე ან ამოიღე; წარდგენისას აღწერე რეალურად გავლილი პროცესი.

## 1. იდეის და პრობლემის ჩარჩო

**პრომპტი**

> იმუშავე როგორც პროდუქტის მკვლევარმა. შემომთავაზე სტუდენტებისთვის რეალური, მცირე მოცულობის ციფრული პროდუქტის იდეა, რომლის პრობლემა ინტერვიუებით შეიძლება შემოწმდეს. იდეას უნდა ჰქონდეს 3 ძირითადი ფუნქცია, არ უნდა საჭიროებდეს ფასიან API-ს ან რთულ backend-ს. გამოყავი ფაქტები, ჰიპოთეზები და ის საკითხები, რომელთა გადამოწმებაც მომხმარებლებთან არის საჭირო.

**რატომ:** იდეა უნდა იყოს რეალისტური და დროის შეზღუდვაში ასაწყობი.  
**შედეგის შეფასება:** იდეა არჩეულია მხოლოდ როგორც ჰიპოთეზა; კვლევის პასუხები ცალკე უნდა შეგროვდეს.

## 2. PRD-ის შექმნა

**პრომპტი**

> შექმენი CampusGo-სთვის მოკლე PRD ქართულად. პროდუქტი არის სტუდენტური ღონისძიებების საძიებელი. ჩართე პრობლემა და სამიზნე მომხმარებელი, MVP-ის ფარგლები, user flow, acceptance criteria, მონაცემთა კონფიდენციალურობა, ტექნოლოგიური სტეკი, შეზღუდვები და მომდევნო ნაბიჯები. არ დაამატო ფუნქციები, რომლებიც ამ ვერსიაში არ მუშაობს; გამოგონილი მონაცემები მკაფიოდ მონიშნე დემოდ.

**იტერაცია:** მოთხოვნები შეიზღუდა ძიებით, კატეგორიის ფილტრით, რჩეულებითა და დეტალების ნახვით; ამოვიღეთ რეალური ავტორიზაცია, გადახდები და რთული backend.

## 3. საიტის საწყისი პრომპტი

**პრომპტი**

> ააწყე CampusGo — მობილურზე მორგებული ქართული ვებ-პროტოტიპი სტუდენტური ღონისძიებებისთვის. გამოიყენე HTML, CSS და Vanilla JavaScript; არ გამოიყენო ფასიანი სერვისი, API key ან backend. დაამატე ღონისძიებების ბარათები, ძიება, კატეგორიების ფილტრი, დეტალების modal და რჩეულები localStorage-ით. მონაცემები მონიშნე დემოდ. ყველა ღილაკი უნდა მუშაობდეს. თუ ფუნქცია მხოლოდ დემოა, მკაფიოდ აუხსენი მომხმარებელს.

## 4. ვიზუალური მიმართულება

**პრომპტი**

> შეიმუშავე CampusGo-ს გამორჩეული ვიზუალური ენა: მუქი მელნისფერი hero, თბილი კრემისფერი ფონი, ნარინჯისფერი აქცენტი და რბილი პასტელური კატეგორიის ილუსტრაციები. გამოიყენე მკაფიო იერარქია, ფართო დაშორებები, მომრგვალებული ბარათები, ქართული ტექსტები და მობილურისთვის ადაპტიური განლაგება. არ გამოიყენო დაუდასტურებელი ფოტოები ან გარე ფოტოები; დეკორატიული ვიზუალები გააკეთე CSS-ით.

**იტერაცია:** გარე ფოტოების ნაცვლად CSS-გრაფიკა აირჩა, რათა ლიცენზიის შემოწმება და დამატებითი asset-ების ატვირთვა არ გამხდარიყო საჭირო.

## 5. ფუნქციური შემოწმება / დებაგი

**პრომპტი**

> შეამოწმე CampusGo-ს JavaScript acceptance criteria-ის მიხედვით: (1) ძიება, (2) კატეგორიის ფილტრი, (3) დეტალების modal, (4) რჩეულის დამატება/წაშლა, (5) რჩეულების ცალკე ნახვა, (6) localStorage-ის შენარჩუნება refresh-ის შემდეგ, (7) ცარიელი შედეგის მდგომარეობა. გამოასწორე მხოლოდ აღმოჩენილი შეცდომები და შეინარჩუნე უკვე მომუშავე ფუნქციები. ბოლოს მომეცი ხელით გასატარებელი ტესტები და გამიჯნე დადასტურებული ქცევა და სავარაუდო ქცევა.

**დეფექტის აღწერის შაბლონი**

**პრომპტი**

## 8. მედიის პრომპტი

საიტის ამ ვერსიაში ფოტოსა და ვიდეოს ფაილები განზრახ არ გამოიყენება. კატეგორიის ვიზუალები CSS ფორმებითაა აგებული. ამიტომ დასაგენერირებელი ფოტო/ვიდეო asset არ არის საჭირო. თუ შემდეგ ფოტო დაემატება, ჯერ შექმენი ის გენერაციული AI-ის პრომპტით, შეინახე პროექტის `assets/` საქაღალდეში და დოკუმენტაციაში ჩაწერე გამოყენებული პრომპტი.

## დამატებითი პრომპტები — კონკრეტული UI ნაწილები

ქვემოთ მოცემული პრომპტები შეიძლება ჩაიწეროს ცალკეულ იტერაციებად, თუ ამ ცვლილებებს AI ხელსაწყოში მართლა გამოიყენებ.

### Header / ნავიგაცია

> შექმენი CampusGo-ს ზედა ნავიგაცია: მარცხნივ ბრენდის ნიშანი და wordmark; მარჯვნივ ღილაკები „ღონისძიებები“, „როგორ მუშაობს“ და „რჩეულები“ რაოდენობის მაჩვენებლით. შეინარჩუნე მკაფიო კონტრასტი, კომპაქტური სიმაღლე და მობილურზე ნავიგაციის გამარტივებული ვერსია. რჩეულების ღილაკმა რეალურად უნდა შეცვალოს ნაჩვენები სია.

### Hero section

> შექმენი CampusGo-ს hero სექცია ქართულად. მთავარი სათაური: „ნუ გამოტოვებ შენთვის მნიშვნელოვანს.“ ქვე-ტექსტმა ერთი წინადადებით ახსნას ღირებულება. დაამატე CTA, რომელიც ღონისძიებების სიაზე გადადის. ვიზუალი იყოს მუქ ფონზე, ნარინჯისფერი აქცენტითა და CSS-ით აწყობილი აბსტრაქტული ფორმებით; არ გამოიყენო გარე ფოტო.

### Event cards / ძიება

> შექმენი ღონისძიების ბარათი თარიღის, კატეგორიის, სათაურის, მოკლე აღწერის, ადგილის, დეტალების ღილაკისა და რჩეულების ღილაკის ადგილებით. ძიებამ უნდა იმუშაოს სათაურზე, კატეგორიაზე, აღწერასა და ადგილზე. ფილტრი და ძიება ერთმანეთს უნდა ერწყმოდეს. თუ შედეგი არ არის, აჩვენე ცარიელი მდგომარეობა და გასუფთავების ღილაკი.

### Footer

> შექმენი მინიმალისტური footer ბრენდის სახელით, ერთწინადადებიანი აღწერითა და პროტოტიპის სტატუსით. არ დაამატო ყალბი სოციალური ქსელების ბმულები, მისამართი ან საკონტაქტო ინფორმაცია.

### ტექსტების გენერაცია

> დაწერე მოკლე, ბუნებრივი ქართული მიკროკოპი სტუდენტური ღონისძიებების პლატფორმისთვის. ტექსტი იყოს მკაფიო და უშუალო; ღილაკების ეტიკეტები მაქსიმუმ 2–4 სიტყვა. არ დაპირდე რეალურ რეგისტრაციას, გადახდას ან ღონისძიების დამოწმებას, თუ ეს ფუნქციები არ მუშაობს.

### ვიზუალური asset (ამ ვერსიაში არ გამოიყენება)

> თუ საიტისთვის აუცილებელი გახდება hero ილუსტრაცია, შექმენი უნიკალური აბსტრაქტული 16:9 გრაფიკა სტუდენტური შესაძლებლობების თემაზე: მელნისფერი მუქი ფონი, თბილი ნარინჯისფერი წრე, პასტელური იასამნისფერი და პიტნისფერი ფორმები, ტექსტისთვის თავისუფალი სივრცე, ყოველგვარი ასოების, ლოგოების, ფოტორეალისტური ადამიანებისა და watermark-ის გარეშე. შეინახე ოპტიმიზებულ WebP/PNG ფორმატში `assets/` საქაღალდეში და გამოიყენე მხოლოდ მას შემდეგ, რაც შეამოწმებ, რომ სურათი ნამდვილად გენერირებულია.

### პრეზენტაციის სტრუქტურა

> მოამზადე 5–7 წუთიანი, 8-სლაიდიანი პრეზენტაცია: პრობლემა, სამიზნე მომხმარებელი, რეალური კვლევა, გადაწყვეტა/MVP, პროტოტიპის დემო, Prompt Engineering-ის იტერაციები, tech stack და დასკვნა. გამოიყენე ერთიანი ვიზუალური სისტემა. არ გამოიგონო კვლევის შედეგები ან URL-ები; დატოვე შესავსები ველები.
