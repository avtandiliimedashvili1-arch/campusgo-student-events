# ჩაბარების checklist — 21 ოქტომბერი

გამოცდის ფაილის მიხედვით, პროექტის ბმულები/ფაილები უნდა გაიგზავნოს **21 ოქტომბერს 14:00-მდე**, ხოლო პრეზენტაცია იწყება **15:00 საათიდან**. მაქსიმალური შეფასება: **25 ქულა**.

## A. აუცილებელი ფაილები და ბმულები

- [ ] GitHub repository საჯაროა და შეიცავს `index.html`, `styles.css`, `script.js`, `favicon.svg`, `README.md` და `docs/`.
- [ ] Live საიტის URL მუშაობს პირად/Incognito ფანჯარაშიც.
- [ ] პრეზენტაციის PPTX ან PDF მიმაგრებულია.
- [ ] პრეზენტაციაში შეცვლილია `[ჩასვი repository URL]` და `[ჩასვი GitHub Pages URL]`.
- [ ] პრეზენტაციის სათაურში ჩაწერილია სტუდენტის სახელი.
- [ ] კვლევის სლაიდზე ჩასმულია რეალური ინტერვიუების მონაცემები.

## B. კვლევა — არ გამოტოვო

- [ ] ჩაატარე მინიმუმ რამდენიმე მოკლე ინტერვიუ სტუდენტებთან (რეკომენდაცია: 3–5).
- [ ] შეავსე `docs/RESEARCH.md` პასუხების ჟურნალი და სინთეზი.
- [ ] არ ჩაწერო გამოგონილი პასუხები, ციტატები ან რესპონდენტების რაოდენობა.
- [ ] პრობლემის აღწერა დააზუსტე იმ პასუხების მიხედვით, რომლებიც რეალურად მიიღე.

## C. Live დემოს ტესტი

- [ ] ძიებაში ჩაწერე `AI` და გადაამოწმე, რომ შედეგები იცვლება.
- [ ] აირჩიე „კარიერა“ და გადაამოწმე კატეგორიის ფილტრი.
- [ ] გახსენი ღონისძიების დეტალები.
- [ ] დაამატე ერთი ღონისძიება რჩეულებში.
- [ ] გახსენი „რჩეულები“ და გადაამოწმე სია.
- [ ] განაახლე გვერდი და ნახე, რომ რჩეული შენარჩუნებულია იმავე ბრაუზერში.
- [ ] დოკუმენტაციაში მკაფიოდ თქვი, რომ ღონისძიებები დემოა და რეალური რეგისტრაცია არ არის ჩართული.

1. GitHub repository URL
2. Live site URL
3. პრეზენტაციის ფაილი ან ბმული
