# CampusGo — სტუდენტური ღონისძიებების საძიებელი

CampusGo არის ქართულენოვანი, მობილურზე მორგებული ვებ-პროტოტიპი სტუდენტური ღონისძიებების აღმოჩენისა და შენახვისთვის.

> **მნიშვნელოვანი:** ღონისძიებები გამოგონილი სადემონსტრაციო მონაცემებია. საიტს არ აქვს რეალური ღონისძიებების წყარო, მომხმარებლის ავტორიზაცია, საერთო მონაცემთა ბაზა, რეგისტრაცია ან ბილეთების გაყიდვა.

## ფუნქციები

- ძიება სათაურით, კატეგორიით, აღწერითა და ადგილით
- კატეგორიებით გაფილტვრა
- ღონისძიების დეტალების modal ფანჯარაში ნახვა
- რჩეულებში დამატება/წაშლა და რჩეულების ფილტრი
- რჩეულების შენახვა მიმდინარე ბრაუზერის `localStorage`-ში
- ადაპტიური მობილური და დესკტოპ დიზაინი
- კლავიატურის მალსახმობი Ctrl/Cmd + K ძიებაზე გადასასვლელად

## ტექნოლოგიური სტეკი

- HTML5 + CSS3
- Vanilla JavaScript
- `localStorage`
- GitHub repository / GitHub Pages
