# CampusGo — სტუდენტური ღონისძიებების საძიებელი

CampusGo არის ქართულენოვანი, მობილურზე მორგებული ვებ-პროტოტიპი სტუდენტური ღონისძიებების აღმოჩენისა და შენახვისთვის.

> **მნიშვნელოვანი:** ღონისძიებები გამოგონილი სადემონსტრაციო მონაცემებია. საიტს არ აქვს რეალური ღონისძიებების წყარო, მომხმარებლის ავტორიზაცია, საერთო მონაცემთა ბაზა, რეგისტრაცია ან ბილეთების გაყიდვა.

## ფუნქციები

- ძიება სათაურით, კატეგორიით, აღწერითა და ადგილით
- კატეგორიებით გაფილტვრა
- ღონისძიების დეტალების modal ფანჯარაში ნახვა
- რჩეულებში დამატება/წაშლა და რჩეულების ფილტრი
- რჩეულების შენახვა მიმდინარე ბრაუზერის `localStorage`-ში
- ადაპტიური მობილური და დესკტოპ დიზაინი
- კლავიატურის მალსახმობი Ctrl/Cmd + K ძიებაზე გადასასვლელად

## გაშვება

ეს არის დამოუკიდებელი სტატიკური ვებგვერდი. გახსენი `index.html` ბრაუზერში; ინსტალაცია, backend ან API გასაღები არ სჭირდება. საიტის UI და JavaScript მოთავსებულია `index.html`-ში.

## GitHub Pages-ზე გამოქვეყნება

1. გახსენი repository-ის **Settings → Pages**.
2. **Build and deployment**-ში აირჩიე **Deploy from a branch**.
3. Branch: `main`; folder: `/(root)`; დააჭირე **Save**.
4. დაელოდე გამოქვეყნებას და დააკოპირე GitHub Pages-ის URL.
5. გახსენი საიტი სხვა/Incognito ფანჯარაში და დატესტე ძიება, კატეგორია, დეტალები და რჩეულები.

## ტესტირება

- [ ] ძიებაში ჩაწერე `AI`; უნდა შემცირდეს ხილული ბარათები.
- [ ] აირჩიე „კარიერა“; უნდა დარჩეს ამ კატეგორიის ღონისძიებები.
- [ ] გახსენი ღონისძიების დეტალები.
- [ ] დაამატე ღონისძიება რჩეულებში და ჩართე „რჩეულები“.
- [ ] განაახლე გვერდი; შენახული რჩეული უნდა დარჩეს იმავე ბრაუზერში.
- [ ] ჩაწერე ძიება, რომელსაც შედეგი არ აქვს; უნდა გამოჩნდეს ცარიელი მდგომარეობა და reset ღილაკი.
